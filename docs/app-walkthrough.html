Critical journeys

1. First manual value

  1. Welcome → eligibility & required legal consent.
  2. Optional profile details and context.
  3. Manual plan → review → explicit activation.
  4. Log a structured meal → review sources → confirm.
  5. Today shows only known, confirmed totals.

2. No-AI fallback

  1. Decline the optional AI-processing consent.
  2. Plan image and meal-photo routes explain they are unavailable.
  3. Manual plan and structured meal entry remain primary.
  4. Morning card uses a deterministic localized template.
  5. No AI outcome ever changes a record without confirmation.

3. Progress without judgment

  1. Mark a day complete only when all intake is logged.
  2. Review seven-day rows with unknown-data markers.
  3. Enable weight tracking separately, if wanted.
  4. Add an explicit measurement, then see a neutral trend.
  5. Never infer a cause from meals or predict an outcome.
